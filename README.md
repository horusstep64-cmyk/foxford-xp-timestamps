# Foxford XP Timestamps

Расширение для записей занятий Фоксфорда. Оно автоматически находит события
типа **«Задача»** с наградой XP и добавляет:

- отдельную вкладку **«⚡ XP»** рядом с чатом и событиями;
- список всех XP-заданий с наградой и таймкодом;
- фиолетовые маркеры заданий на таймлайне видео;
- переход к заданию одним нажатием.

Расширение работает на всех страницах вида `https://foxford.ru/groups/*`.
Таймкоды берутся из штатного списка событий записи, поэтому для каждого урока
они определяются автоматически.

## Установка в Яндекс Браузер

1. Нажмите **Code → Download ZIP** на странице репозитория.
2. Распакуйте архив в отдельную папку.
3. Откройте в Яндекс Браузере `browser://extensions/`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите распакованную папку, внутри которой лежит `manifest.json`.
7. Обновите открытую запись занятия Фоксфорда.

## Установка в Chrome или Edge

1. Скачайте и распакуйте репозиторий.
2. Откройте `chrome://extensions/` или `edge://extensions/`.
3. Включите режим разработчика.
4. Выберите **Загрузить распакованное расширение** и укажите папку проекта.
5. Обновите страницу записи.

## Использование

Откройте запись занятия. Справа, рядом с вкладками **«Чат»** и **«События»**,
появится вкладка **«⚡ XP»**. В ней будут показаны все найденные задания.
Нажатие на строку или на маркер таймлайна переводит запись к соответствующему
заданию.

## Как находятся задания

Фоксфорд уже хранит в записи полный список событий. Расширение выбирает только
события с XP-наградой, считывает их штатные таймкоды и связывает новые элементы
интерфейса с оригинальным событием. Анализ видео и внешние сервисы не нужны.

## Приватность

Расширение работает только внутри страницы записи. Оно не сохраняет чат,
не собирает данные аккаунта и не отправляет информацию на внешние серверы.
